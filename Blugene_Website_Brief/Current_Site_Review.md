# 현재 사이트 관찰과 개선 판단

확인일: 2026-09-06  
공개 홈페이지: https://cutisbioindigo.kr/ko  
관찰 범위: 홈페이지의 공개 DOM, 첫 화면, 스크롤 후 시험 이미지 영역, 메뉴·언어 선택. 관리자·저장소·문의 전송·내부 하위 페이지의 전체 동작은 점검하지 않음.

## 직접 관찰한 내용

- 현재 표시 브랜드는 CutisBio Indigo이며 Blugene이 첫 화면에 나타나지 않았습니다.
- Hero는 숲속에서 데님을 입은 사람의 장면과 중앙의 큰 제목으로 구성되어 있습니다.
- 메뉴는 홈, 회사 소개, 기술 소개, 최신 소식, 문의하기입니다.
- 언어 선택은 ko/en/ja/zh/bn/tr 6개 언어입니다.
- 인증 이미지 4종, 일본어 원단 비교사진, 제조 4단계, CEO 인터뷰 형식의 인용문, 여러 매체 이름을 반복하는 영역이 있습니다.
- 원단 비교사진은 실제 스크롤 진입 후 로딩됐습니다. 초기 naturalWidth=0이라는 결과만으로 깨진 이미지라고 결론내리지 않았습니다.
- 밝은 영역에서 상단 헤더의 흰 글자 대비가 부족해 보였습니다.
- 스크롤 전 전체 페이지 캡처에는 본문 일부가 비어 보였습니다. 이는 스크롤 애니메이션·지연 로딩과 관련될 가능성이 있으나 원인 코드를 확인한 결론은 아닙니다.

## 디자인·구현 제안

- Blugene과 카탈로그의 가족·데님 이미지를 전면에 배치하고 핵심 CTA를 샘플 문의로 연결합니다.
- 브랜드 선언 뒤에 구체적인 시험자료를 배치해 감성과 증거의 흐름을 만듭니다.
- 카탈로그의 모든 핵심 장을 홈과 상세 페이지에 대응시키고, 빠져 있던 색상·제품 형태·프린팅 사례를 확장합니다.
- 기존 일본어 시험사진은 별도 출처를 확인해 유지 여부를 결정하고 카탈로그 시험과 혼합하지 않습니다.
- 매체 명칭과 인터뷰는 실제 근거가 있는지 확인하고, 없는 경우 삭제합니다. 근거가 없다는 사실을 이번 검토에서 확정한 것은 아닙니다.
- 모든 본문을 기본적으로 읽을 수 있게 하고, 모션은 가시성의 필수 조건이 되지 않게 합니다.
- 공개 사이트를 개편하는 지시문이며, 여기서 코드 변경이나 배포를 수행하지 않았습니다.

## 제공 카탈로그의 역할

이 검토의 주된 콘텐츠 근거는 `source/CutisBio_CB_Bioindigo_Catalogue_(EN)_July 2026.pdf`입니다. `data/evidence.json`의 숫자와 날짜는 카탈로그를 전사한 것이며 최신 원시험성적서나 인증기관 데이터베이스 조회 결과가 아닙니다. 브랜드 카피와 디자인 선택은 이번 작업의 제안입니다.
