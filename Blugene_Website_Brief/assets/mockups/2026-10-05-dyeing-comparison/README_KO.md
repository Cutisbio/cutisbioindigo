# 염색 비교 SVG 사용법

- `Blugene_Dyeing_Comparison_KO.svg`: 한국어. 행은 석유화학 인디고·Blugene 1·Blugene 2, 열은 1회·3회·5회.
- `Blugene_Dyeing_Comparison_EN.svg`, `Blugene_Dyeing_Comparison_JA.svg`: 영어·일본어.
- `Blugene_Label_Editor.html`: 웹브라우저에서 열고 언어를 선택하거나 여섯 문구를 직접 수정한 다음 **SVG 저장**을 누르세요. 인터넷 연결이나 설치가 필요 없습니다. 표기는 입력 즉시 반영됩니다.
- 글자는 SVG 텍스트이므로 Illustrator·Inkscape 등에서 직접 수정할 수도 있습니다. 글꼴은 사용 환경의 대체 글꼴에 따라 조금 달라질 수 있습니다.

원본의 위쪽 세 행만 사용했습니다. 사진은 색 보정 없이 보존한 래스터 이미지이며, 글자·레이아웃은 벡터입니다. SVG 확대가 사진의 원본 해상도를 늘리지는 않습니다. 출력 크기는 2,520×1,490 SVG 단위, 내장 사진은 1,952×1,244픽셀입니다. 각 SVG와 편집 HTML은 사진을 파일 안에 포함하므로 별도 이미지 파일이 필요 없습니다.

`Source_Download_Index.md`에서 사용한 PDF의 위치와 확인 범위를 볼 수 있습니다. 이 작업은 기존 보고서의 그림 편집이며 새 공식 보고서 접수·완료 등록은 아닙니다.
