# Blugene 홈페이지 개선 패키지

신규 브랜드명은 **Blugene by CutisBio**입니다. 이 패키지는 Claude Code에서 현재 cutisbioindigo.kr 저장소를 개선할 때 쓰는 실행 지시문과 원본 시각자료입니다. 홈페이지 자체를 수정하거나 배포한 결과물은 아닙니다.

## 사용 방법

1. ZIP을 내려받아 압축을 풉니다.
2. 압축 안의 `Blugene_Website_Brief` 폴더를 **cutisbioindigo.kr 프로젝트 루트**에 넣습니다.
3. 해당 프로젝트에서 Claude Code를 열고 다음 문장을 전달합니다.

```text
Blugene_Website_Brief/Blugene_Claude_Code_Master_Prompt.md를 끝까지 읽고 지시대로 현재 홈페이지를 개선해줘. 같은 폴더의 원본 PDF, 이미지, evidence.json과 catalogue-assets.json을 함께 확인하고 활용해줘. 제안으로 끝내지 말고 실제 코드 수정, 로컬 미리보기, 검증까지 완료한 후 한국어로 결과를 보고해줘.
```

프롬프트 파일만 사용한다면 원본 PDF를 Claude Code가 접근 가능한 프로젝트 폴더에 함께 두고, 프롬프트 전체를 전달해도 됩니다. ZIP에는 원본 PDF가 이미 포함돼 있습니다.

## 들어 있는 자료

| 경로 | 내용 |
|---|---|
| `Blugene_Claude_Code_Master_Prompt.md` | 브랜드 카피, 화면 구성, 자료 사용 위치, 시각자료 제작 브리프, 다국어·보안·검증 지시 |
| `Catalogue_Contact_Sheet.jpg` | 카탈로그 12쪽 전체를 한눈에 보는 미리보기 |
| `source/` | 제공받은 원본 PDF와 추출 텍스트. 원본 PDF는 수정하지 않음 |
| `assets/catalogue/embedded/` | PDF 내장 이미지 71개. 사진 외에 로고·아이콘·부분 이미지 포함 |
| `assets/catalogue/figures/` | 실제 사용에 유용한 주요 도판 영역 19개 |
| `assets/catalogue/pages/` | 전체 12쪽 미리보기 |
| `data/catalogue-assets.json` | 이미지 파일, 출처 페이지, 원본 위치, 활용 목적 |
| `data/evidence.json` | 핵심 수치, 비교시험 데이터, 인증서 기재사항, 적용 범위 |
| `Current_Site_Review.md` | 현재 공개 사이트 관찰 내용과 개선 이유 |

새로 생성한 사진을 이 패키지의 실물 시험자료에 섞지 않았습니다. 프롬프트 안의 추가 이미지 제작 브리프는 별도의 브랜드 표현을 위한 것입니다. 추가 시각 참고안이 대화에 표시되는 경우에도 구현 완료 화면이나 시험 결과를 의미하지 않습니다.

## 제안과 자료의 구분

**제공 자료에서 확인한 내용**: 바이오 기반 탄소 함량 98%, 아닐린과 N-메틸아닐린 불검출(방법 검출한계 5 mg/kg), 원단·견뢰도·색상·프린팅 비교자료, 인증서 이미지. 원시험성적서 전체나 실시간 인증기관 조회까지 완료했다는 의미는 아닙니다.

**사용자가 지정한 메인 문구**:

- 상단 설명: **인디고DNA와 발효로 빚어낸 푸른색.**
- 메인 제목: **평생 함께하는 데님, 더 안전한 파랑.**
- 본문: **피부에 평생 접촉하는 그 푸른색이 합성생물학으로 재탄생했습니다. 피부건강을 위해 작은 위험까지 타협하지 않는 인디고 Blugene.**

**그 밖에 제안한 내용**: Blugene 브랜드 서사, 화면 순서, 색상 팔레트, 문의 동선, 추가 이미지 제작안. 영어 Hero도 새 한국어 문구에 맞춰 변경했습니다.

**표현을 조정한 내용**: ‘평생 접촉해도 피부에 안전함이 입증됐다’는 문장을 시험결과로 쓰지 않고, ‘평생 입는 옷이므로 불순물 관리에 타협하지 않는다’는 브랜드 철학으로 반영했습니다. 98% 바이오 기반 탄소를 인디고 순도로 표기하지 않으며, 불검출을 절대적 0으로 바꾸지 않습니다.
