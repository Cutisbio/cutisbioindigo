`npm run check:blugene` (빌드 전에 자동 실행)이 문서상 유효기간을 검사해 **만료 90일 전부터 경고**한다.
만료 자체는 빌드를 막지 않는다 — 화면이 이미 '문서 기재 유효기간이 지났습니다 · 최신 자료를 문의해 주세요'로
정확히 렌더링하기 때문이다(`documentStatus()` + 하루 단위 재생성). 반면 시험 수치·번호가 카탈로그와 어긋나면 빌드를 막는다.

"피부건강을 위해 … 타협하지 않습니다"는 시험을 하고 결과를 공개한다는 태도(동기)이지 유해물질이 전혀 없다거나 피부에 안전하다는 뜻이 아니다. 둘째 설명문은 "데님은 하루 종일 피부에 닿는 옷"이라는 사실과 "합성 인디고에 남을 수 있는 아닐린 · N-메틸아닐린"(카탈로그 p.4 · A-2 Cordin 2021 의 범위)만 말하고, 건강 영향 수치는 홈에 두지 않는다(C 표 「건강 영향 서술」). "친환경과 지속가능성에 대해 공식인증을 통해 증명합니다"는 사이트에 실은 인증서(ZDHC MRSL · OEKO-TEX ECO PASSPORT · USDA BioPreferred · OK biobased)가 다루는 범위 — 제한물질 관리와 바이오 기반 함량 — 를 가리키며, 피부 안전성 입증이나 탄소중립 · 배출 저감 · LCA 같은 환경 성과 수치(C 표 「환경 성과 수치」)를 뜻하지 않는다. 이전 문구는 "원료를 밝힙니다" · "불순물을 확인합니다" · "원본을 보여드립니다", 둘째 · 셋째 소제목의 직전 문구는 "미량의 불순물과도 타협하지 않습니다" · "공식인증을 통해 증명합니다". |

## D. 사이트에서 절대 쓰지 않는 표현

`npm run check:blugene` 이 `messages/*.json` 전체를 검사해 아래 표현을 막는다.
(단, "우리가 주장하지 않는 것"을 밝히는 문단은 예외로 통과시킨다.)

- `0 ppm`, `완전 무함유`, `전혀 없음`, `완벽 차단`, `원천 배제`, `chemical-free`
- `100% 안전`, `평생 안전 입증`, `임상 입증`, `피부과 입증`
- `탄소중립`, `배출 제로`, `net-zero`, `생분해`, `물 80~90% 절감`
- `모든 항목에서 우월`
- 브랜드 · 법인 표기 오류: `BluGene`, `Bluegene`, `BlueGene`, `BluGen`, `Blugene®`, `Cutis Bio`, `Cutis Biyo`
- 비-한국어 파일에 한국어 원문이 남아 있는 경우 (자동 번역 실패의 흔적)

검사 패턴에는 한국어 · 영어 외에 일본어 · 중국어 · 터키어 · 벵골어 표현도 넣었지만,
언어별 표현을 모두 담을 수는 없다. **새 문구를 추가할 때는 이 문서의 A/B/C 구분을 사람이 직접 확인해야 한다.**

### 이미지에 구워진 글자는 이 검사를 통과한다

정규식은 `messages/*.json` 의 값만 본다. 이미지 안의 글자는 보지 못한다.
실제로 `aniline-infographic.png` 가 `Aniline-Free & Safe` 를 담은 채 검사를 통과했고,
사람이 이미지를 열어 보고서야 발견했다.
**`public/` 에 새 이미지를 넣을 때는 이미지 안의 글자를 사람이 직접 확인한다.**
